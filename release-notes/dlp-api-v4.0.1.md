# Release Notes

## dlp-api 4.0.1

`cleartext_with_insertable` now gives a signer meta a signer-table entry when its pubkey was previously inserted as a non-signer. It also permits a non-signer meta to reuse an inserted signer entry. The compact action serialization and public API are unchanged.

When a new signer entry is required, the caller must supply that pubkey as a signed account to `DelegateWithActions`. The non-signer-to-signer case generated by `dlp-api` 4.0.0 was rejected by the program already; 4.0.1 corrects its table index. The signer-to-non-signer case requires the matching program fix in `dlp@v2.0.1`.
